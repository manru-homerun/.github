>'야단법석'은 프로야구 원정 관람 팬의 소비를 지역 관광으로 확장하는 모바일 앱 서비스입니다. 응원 구단의 경기 일정에 맞춘 개인화된 여행 코스를 AI 기반으로 계획하고 친구와 공유할 수 있도록 합니다. 90% 이상 야구팬이 동행자와 관광한다는 자료에 착안해, 동행자 배려 조건까지 고려해 여행지를 선정합니다. 또한 지역별 인기 여행지와 티맵 데이터 기반 중심 관광지를 추천해, 새로운 여행지를 추천받고 저장합니다. 더 나아가 GPS 기반 위치 인증 기능과 스티커 보상으로 단순한 여행 계획을 넘어 실제 방문까지 유도합니다.
